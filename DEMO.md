# Demo recording checklist

Record a 60–90 second screen capture:

1. Show the NEXUS Discord server and the connected Switch room/agent configuration.
2. Run `/health`.
3. Run `/task description: Inspect the project and add a small unit test for the greeting utility. Do not change unrelated files.`
4. Show the task appear in the Switch room and Codex start working.
5. Show Codex's completed response routed back through NEXUS into the same Discord channel.
6. Run `/job <id>` and show `completed`.

Do not stage a fake completion. If the Switch bridge is not implemented/configured, show the `needs_setup` status and describe the integration as in progress, not complete.

Before recording, remove tokens and private data from the screen.
